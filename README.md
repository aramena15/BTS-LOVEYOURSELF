BTS LOVE YOURSELF

Aplicación Android inspirada en BTS y su comunidad ARMY.

Funcionalidades

- Inicio: bienvenida a la experiencia BTS ARMY.
- Miembros: información visual de los siete integrantes.
- Discografía: consulta de canciones mediante Retrofit.
- Quiz: preguntas sobre BTS.
- Perfil: pantalla de perfil del usuario.

Tecnologías

- Kotlin
- Android Studio
- Jetpack Compose
- Retrofit
- API de canciones

Objetivo

Desarrollar una aplicación Android con pantallas conectadas y componentes de interfaz reutilizables.
